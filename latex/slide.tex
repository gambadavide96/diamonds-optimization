\begin{frame}{Introduction}
    The objective of this study is to conduct a comparative analysis of the convergence behavior of various optimization algorithms applied on a Ridge Regression problem to the Diamonds Dataset.
    
    \vspace{0.3cm}
    In particular, the focus is on:
    \begin{itemize}
        \item Evaluating the respective algorithms convergence rates.
        \item Investigating how theoretical properties of the objective function (such as Convexity, Smoothness ecc..) have an impact to results.
        \item Analyzing how the $L_2$ regularization parameter ($\lambda$) of Ridge Regression influences algorithms behavior.
    \end{itemize}
    
    \vspace{0.3cm}
    The following algorithms were implemented:
    \begin{itemize}
      \item Gradient Descent (Naive, Bounded, Smooth). 
      \item Accelerated Gradient Descent (Nesterov's).
      \item Mini-Batch Stochastic Gradient Descent (Decaying Learning rate)
      \item Newton's Method.
      \item Adagrad.
    \end{itemize}

\end{frame}

\begin{frame}{Dataset Characteristics: Feature correlation}

    \textbf{Multicollinearity:} \\

        \item Given the high multicollinearity among the features in the matrix $X$, we expect small eigenvalues for the Normal Matrix $X^T X$ and a loss objective landscape with flat and elongated valleys.
        \item Consequently, the optimization problem is \textbf{ill-conditioned} and particularly challenging for gradient-based methods.
        \item We will demonstrate that we can mitigate this issue by using Ridge Regression instead of standard linear regression.
    \end{itemize}

\begin{frame}{Ridge Regression}
    \textbf{Ridge Regression} problem extends Ordinary Least Squares (OLS) by imposing an $L_2$ penalty on the model parameters to mitigate overfitting and multicollinearity.

    \vspace{0.1cm}

    The objective function is the mean squared errors for each data point ($i=1$ to $n$) plus the sum of squared weights (from $j=1$ to $d$).

    $$f(w) = \frac{1}{2n} \sum_{i=1}^{n} (y_i - x_i^T w)^2 + \frac{\lambda}{2} \sum_{j=1}^{d} w_j^2$$

    We can define it in vector notation as follows:

    $$
    f(w) = \underbrace{\frac{1}{2n} \| y - Xw \|^2}_{\text{Half MSE}} + \underbrace{\frac{\lambda}{2} \| w \|^2}_{\text{Regularization}}
    $$

    Where:
    \begin{itemize}
        \item $X \in \mathbb{R}^{n \times d}$ is the feature matrix (includes a column of 1).
        \item $y \in \mathbb{R}^n$ is the target variable (price).
        \item $w \in \mathbb{R}^d$ is the weights vector.
        \item $\lambda > 0$ is the regularization hyperparameter.
    \end{itemize}
\end{frame}

\begin{frame}{Gradient and Hessian Matrix}
    Since $f(w)$ is differentiable everywhere, we can compute the first-order derivative (the Gradient) and second-order derivative (the Hessian matrix).\\[0.2cm]
    We will use them later in optimization's algorithm and to investigate the property of $f(w)$. \\[0.2cm]

    \vspace{0.2cm}
    \textbf{The Gradient $\nabla f(w)$}
    $$\nabla f(w) = \frac{1}{n} X^T (Xw - y) + \lambda w$$

    \textbf{The Hessian Matrix $\nabla^2 f(w)$}
    $$ H = \nabla^2 f(w) = \frac{1}{n} X^T X + \lambda I$$
\end{frame}

\begin{frame}{$f(w)$ is strictly convex}
    To investigate the convexity of our objective function, we rely on the Second-order Characterization of Convexity: \\[0.3cm]

    \begin{itemize}
        \item \textit{If $ \nabla^2 f(\mathbf{x}) $ exists at every point $\mathbf{x} \in \mathrm{dom}(f)$ and is symmetric. Then $f$ is convex if and only if $\mathrm{dom}(f)$ is convex, and for all $\mathbf{x} \in \mathrm{dom}(f)$, we have
        $ \nabla^2 f(\mathbf{x}) \succeq 0 $. So $\nabla^2 f(\mathbf{x})$ is \textbf{positive semidefinite}.}
        \item \textit{A symmetric matrix $M$ is Positive Semi-Definite if $v^T M v \ge 0$ for all vectors $v$, and Positive Definite if $v^T M v > 0$ for all non-zero vectors $v \neq 0$.}\\[0.3cm]

    \end{itemize}

    Let's apply this definition to our Ridge Regression Hessian matrix, analyzing its quadratic form $v^T H v$ for any arbitrary non-zero vector $v \in \mathbb{R}^d$:

    $$v^T H v = v^T \left( \frac{1}{n} X^T X + \lambda I \right) v$$

\end{frame}

\begin{frame}{$f(w)$ is strictly convex}
    Solving the quadratic form, we get:
    $$v^T H v = \underbrace{\frac{1}{n} \|Xv\|^2}_{\text{OLS Base}} + \underbrace{\lambda \|v\|^2}_{\text{Ridge Penalty}}$$

    \begin{itemize}
        \item \textbf{The OLS Base:} The squared norm $\|Xv\|^2$ is a squared length, meaning it is always non-negative ($\ge 0$).
        \item \textbf{The Ridge Penalty:} For any non-zero vector $v \neq 0$, its squared norm $\|v\|^2$ is strictly positive. Since our regularization hyperparameter is strictly positive ($\lambda > 0$), the entire term $\lambda \|v\|^2$ is strictly greater than zero ($> 0$).
    \end{itemize}

    Because we are adding a strictly positive term to a non-negative term, the entire sum is guaranteed to be strictly positive.\\[0.1cm] 
    Adding the ridge penalty guarentee us that Hessian matrix $H$ is \textbf{Positive Definite} and consequently the objective function possesses a single unique global minimum, so that means $f(w)$ is strictly convex.
\end{frame}

\begin{frame}{Ridge Regression - Properties}
    To understand how optimization algorithms will behave on Ridge Regression objective function $f(w)$, we must analyze its properties. 

    \vspace{0.3cm}
    \textbf{1. Convexity: Yes (Strictly Convex)} \\
    As proven in the previous section, the addition of the $L_2$ penalty ensures that the Hessian matrix $H$ is Positive Definite. Therefore, the function is not just convex, but \textbf{strictly convex}. This guarantees that any local minimum is the unique global minimum $w^*$.

    \vspace{0.3cm}
    \textbf{2. Lipschitz Continuous: No (Globally)} \\
    A function $f(w)$ is globally $B$-Lipschitz if its gradients are bounded in magnitude everywhere ($\| \nabla f(w) \| \le B$). 
    Our objective function $f(w)$ is a quadratic function. As the weights $w$ can grow toward infinity, the gradient $\nabla f(w) = \frac{1}{n} X^T (Xw - y) + \lambda w$ also can grows linearly toward infinity. Because the gradient is unbounded over the entire domain $\mathbb{R}^d$, the function itself is \textbf{not globally Lipschitz continuous}.
\end{frame}

\begin{frame}{Ridge Regression - Properties}

    \textbf{3. Smoothness ($L$-smooth): Yes} \\
    It is \textbf{$L$-Smooth}.
    The curvature does not change abruptly and the gradient doesn't oscillate wildy, the function always lies \textit{below} a certain parabola: 

    $$f(y) \le f(x) + \nabla f(x)^T (y - x) + \frac{L}{2} \|x - y\|^2 \quad \forall x,y$$

    \begin{itemize}
        \item \textbf{Value of $L$:} It corresponds to the largest eigenvalue of the Hessian matrix (the maximum curvature of the loss landscape).
          $$L = \lambda_{\max}\left(\frac{1}{n}X^T X\right) + \lambda$$
        \item \textbf{Consequence:} This value acts as the absolute \textbf{speed limit} for Gradient Descent. The optimal safe step size is $\gamma = \frac{1}{L}$.
    \end{itemize}
\end{frame}

\begin{frame}{Ridge Regression - Properties}
    
    \textbf{4. Strong Convexity ($\mu$-strongly convex): Yes} \\
    It is \textbf{$\mu$-Strongly Convex}.
    The curvature is "at least" $\mu$ in every direction. The function always lies \textit{above} the quadratic function:

    \vspace{-0.2cm}
    $$f(y) \ge f(x) + \nabla f(x)^T (y - x) + \frac{\mu}{2} \|x - y\|^2 \quad \forall x,y$$
    \vspace{-0.2cm}

    \begin{itemize}
        \item \textbf{Value of $\mu$:} It corresponds to the smallest eigenvalue of the Hessian matrix.
          $$\mu = \lambda_{\min}\left(\frac{1}{n}X^T X\right) + \lambda$$
        \vspace{0.2cm}
        \item \textbf{Consequence:} $\mu$ indicates how much the function is strongly convex.
    \end{itemize}
\end{frame}

\begin{frame}{The effect of $L2$ regularization}
    Specifically, increasing $\lambda$ directly increases $\mu$, the \textbf{strong convexity parameter}. \\[0.1cm]
    When we set a large $\lambda$, the minimum curvature ($\mu$) is strictly bounded away from zero, the loss function becomes steeper and we eliminate flat regions where Gradient's based method might stall.\\[0.1cm]

\begin{frame}{Dataset pre-processing steps}
    
    To prepare the dataset for our optimization algorithms, we now apply the following preprocessing steps:
    \vspace{0.2cm}

    \begin{itemize}
        \item \textbf{Ordinal Encoding:} Categorical variables (\texttt{cut}, \texttt{color}, \texttt{clarity}) were mapped to integer values, preserving their inherent hierarchy. 
        \item \textbf{Removing Outliers:} We filter out extreme anomalous data points.
        \item \textbf{Standardize the Features ($X$) and the Target ($y$):} By subtracting the mean and dividing by the standard deviation, we ensure all features and the target share the same scale (a mean of 0 and a variance of 1), also it allows Gradient Descent to point much more directly toward the minimum.
        \item \textbf{The Bias Trick (Adding a column of 1s):} We append a column of ones to our feature matrix $X$ to absorb the intercept (or bias) term directly into our weight vector $w$.
    \end{itemize}
\end{frame}

\begin{frame}{Gradient Descent - Naive Learning Rate}

    \textbf{Gradient descent} by definition updates the weight vector $w$ step-by-step by moving in the opposite direction of the gradient, scaled by the learning rate (step size) $\gamma$:
    $$w^{(t+1)} = w^{(t)} - \gamma \nabla f(w^{(t)})$$

    \vspace{0.1cm}

    For this first run, we are using a \textbf{naive, very small learning rate $\gamma$ = 0.0001 }. \\[0.2cm]
    Choosing a very small step size is a conservative and highly stable approach: it guarantees that our algorithm will not overshoot the minimum or diverge. \\[0.2cm]
    But this safety comes with a heavy trade-off in efficiency: taking such microscopic steps means the algorithm might require a massive number of iterations to finally reach the optimal solution.
    
\end{frame}

\begin{frame}{Gradient Descent - Assuming Bounded Gradient}
    
    Assume the distance between initial solution and optimal solution is bounded by $R$ and this bounded region contains all iterates. \\[0.1cm]
    Since we initialize our initial solution vector to \textbf{Zero} (\texttt{np.zeros}), the distance coincides exactly with the norm of the solution:
    $$\|w_0 - w^*\| \le R$$
    $$\|0 - w^*\| = \|w^*\| \le R$$

    The assumption on $R$ means: \textit{"The optimal solution and the optimization path to reach it lie within a sphere of radius $R$."}

    \begin{itemize}
        \item Since we have \textbf{standardized the data} ($X$ and $y$ have zero mean and unit variance), the optimized weights $w$ will naturally be small (typically between -1 and 1)
        \item We set \textbf{$R = 5.0$}. A generous safety margin (a "Bounded Region") that is virtually guaranteed to contain the true solution.
    \end{itemize}
\end{frame}

\begin{frame}{Gradient Descent - Assuming Bounded Gradient}
    \small
    We need to find a number $B$ such that $\|\nabla f(w)\| \le B$ for every $w$ within the radius $R$.

    We rewrite the gradient formula in this way:
    $$\nabla f(w) = \left(\frac{1}{n}X^T X + \lambda I\right)w - \frac{1}{n}X^T y$$

    Using the triangle inequality ($\|a + (-b)\| \le \|a\| + \|b\|$) and the definition of matrix norms:
    $$\|\nabla f(w)\| \le \underbrace{\left\| \frac{1}{n}X^T X + \lambda I \right\|}_{\text{This is smooth parameter L}} \cdot \underbrace{\|w\|}_{\le R} + \underbrace{\left\| \frac{1}{n}X^T y \right\|}_{\text{Constant}}$$

    \vspace{0.3cm}
    So the formula for $B$ is:
    $$B = L \cdot R + \left\| \frac{1}{n}X^T y \right\|$$
\end{frame}

\begin{frame}{Gradient Descent - Assuming Bounded Gradient}
    By making the assumption that our optimization path remains within a bounded region $\|w_0 - w^*\| \le R$, and having calculated the maximum gradient bound $B$ such that $\|\nabla f(w)\| \le B$ for all $w$, we have effectively established that our objective function is \textbf{$B$-Lipschitz continuous} within this domain. 

    \vspace{0.4cm}
    For Lipschitz continuous functions, optimization theory provides a specific, optimal step size: we can now set $\gamma$ using the formula:
    
    $$\gamma = \frac{R}{B \sqrt{T}}$$

    where $T$ = 10.000 iterations.
\end{frame}

\begin{frame}{Gradient Descent - Smoothness}

    Previously we have seen that function is \textbf{$L$-Smooth}.

    \vspace{0.3cm}
    \begin{itemize}
        \item \textbf{Value of $L$:} It is the largest eigenvalue of the Hessian matrix (the maximum curvature).
          $$L = \lambda_{\max}\left(\frac{1}{n}X^T X\right) + \lambda$$
          or equivalently
          $$L = \left\| \frac{1}{n}X^T X \right\| + \lambda$$
          
        \vspace{0.2cm}
        \item \textbf{Consequence:} This value is the \textbf{speed limit} for Gradient Descent. If we use a learning rate $\gamma > \frac{2}{L}$, the algorithm will diverge. The optimal safe step size is $1/L$.
    \end{itemize}
\end{frame}

\begin{frame}{Nesterov's Accelerated Gradient Descent}
    Now we implement the \textbf{Accelerated Gradient Descent} algorithm. This method improves standard gradient descent by computing the next iteration point as a dynamically weighted average between a conservative "smooth" step and a more "aggressive" step. 

    \vspace{0.3cm}
    Choosing arbitrary initial points $\mathbf{z}_0 = \mathbf{u}_0 = \mathbf{w}_0$, for $t \ge 0$ we set:

    $$\mathbf{u}_{t+1} := \mathbf{w}_t - \frac{1}{L} \nabla f(\mathbf{w}_t)$$
    $$\mathbf{z}_{t+1} := \mathbf{z}_t - \frac{t+1}{2L} \nabla f(\mathbf{w}_t)$$
    $$\mathbf{w}_{t+1} := \frac{t+1}{t+3} \mathbf{u}_{t+1} + \frac{2}{t+3} \mathbf{z}_{t+1}$$

    \begin{itemize}
        \item \texttt{w} represents the main weight vector.
        \item \texttt{u} represents the prudent/smooth update.
        \item \texttt{z} represents the aggressive update.
    \end{itemize}
\end{frame}

\begin{frame}{Stochastic Gradient Descent with Mini-batches}
    \textbf{Mini-batch Stochastic Gradient Descent (SGD)} approximate the true gradient using a much smaller, randomly selected subset of the data of size $m$ (where $m < n$). 

    \vspace{0.2cm}
    Starting from an initial point $\mathbf{x}_0 \in \mathbb{R}^d$, at each iteration $t$ we choose a random subset of indices $\{h_1, \dots, h_m\} \subseteq \{1, \dots, N\}$ and update the weights using a learning rate $\gamma_t \ge 0$:

    $$\mathbf{w}_{t+1} := \mathbf{w}_t - \gamma_t \frac{1}{m} \sum_{j=1}^m \nabla f_{h_j}(\mathbf{w}_t)$$

    \begin{itemize}
        \item The algorithm operates in "epochs". At the start of an epoch, the entire dataset is randomly shuffled (\texttt{np.random.permutation}).
        \item Within an epoch, a loop sequentially iterates over this shuffled data and cut them in chunks of size \texttt{batch\_size} (our $m$).
        \item At each iteration the \texttt{minibatch\_gradient} function calculates gradient on a small chunk, and the main loop updates the weights.
    \end{itemize}

\end{frame}

\begin{frame}{Mini batches SGD - Decaying Learning Rate}
    Since our objective function is $\mu$-strongly convex. From \textbf{Tame Strong Convexity}, the learning rate to use is:
    
    $$\gamma_t = \frac{2}{\mu(t+1)}$$
    
    and it decays over each iteration.

    \vspace{0.4cm}
    However, applying this formula naively when our regularization parameter $\lambda$ is small leads to immediate divergence.

    \vspace{0.2cm}
    \begin{itemize}
        \item If $\mu$ is very small, the initial step size $\gamma_t$ becomes very large. 
        \item This massively exceeds our theoretical $L$-smoothness "speed limit" ($2/L$), causing the algorithm to diverge.
    \end{itemize}
\end{frame}

\begin{frame}{Mini batches SGD - Decaying Learning Rate}
    \small
    Looking closely at our calculated strong convexity parameters ($\mu$), we can demonstrate why applying the classic theoretical decay rate $\gamma_t = \frac{2}{\mu(t+1)}$ causes divergence. 

    \vspace{0.3cm}
    For our smallest ridge penalization ($\lambda = 10^{-5}$), the minimum curvature of our loss function is extremely flat, resulting in $\mu \approx 0.00130$. If we plug this value into the pure \textbf{Tame Strong Convexity} formula to calculate the learning rate for our very first iteration ($t=0$), we get:
    $$\gamma_0 = \frac{2}{0.00130} \approx 1538$$

    \vspace{0.3cm}
    This initial step size is catastrophically large. As we established earlier, the absolute maximum safe step size before an algorithm diverges is bounded by the smoothness parameter $(2/L) \approx 0.46.$ An initial step of $1538$ massively violates this theoretical "speed limit".

    \vspace{0.3cm}
    This same issue occurs across all other small values of the ridge regularization parameter $\lambda$.
\end{frame}

\begin{frame}{Mini batches SGD - Decaying Learning Rate}
    \small
    To safely apply the optimal decay rate by the \textbf{Tame Strong Convexity}, we propose an adjusted learning rate:
    
    $$\gamma_t = \frac{2}{L + \mu(t+1)}$$

    \vspace{0.4cm}
    In this way we get:
    
    \vspace{0.2cm}
    \begin{itemize}
        \item \textbf{Initial Stability ($t=0$):} At the very first iteration, the learning rate evaluates to exactly $\frac{2}{L+\mu} < \frac{2}{L}$. This respect the theoretical optimal speed limit for smooth strongly convex functions, acting as a safety cap that prevents the algorithm from diverging, regardless of how small $\mu$ is.
        
        \vspace{0.3cm}
        \item \textbf{Asymptotic Convergence ($t \to \infty$):} As the iterations progress, the $L$ term becomes dominated by $\mu t$. The learning rate transitions to approximate $\frac{2}{\mu t}$, strictly adhering to the decay rate required to suppress the stochastic noise of the mini-batches and guarantee convergence to the global minimum.
    \end{itemize}
\end{frame}

\begin{frame}{Newton's Method}
    Until now, we have relied on first-order optimization algorithms (like Gradient Descent and its variants), which only use the gradient (the slope) to update weights. \\[0.2cm]
    \textbf{Newton's Method} introduces a massive upgrade by incorporating second-order derivative information—specifically, the curvature of the loss landscape represented by the Hessian matrix $\nabla^2 f(\mathbf{x})$. 

    \vspace{0.4cm}
    Mathematically, for minimizing a convex function $f: \mathbb{R}^d \rightarrow \mathbb{R}$ in the $d$-dimensional case, the update rule is defined as:

    $$\mathbf{w}_{t+1} := \mathbf{w}_t - \nabla^2 f(\mathbf{w}_t)^{-1}\nabla f(\mathbf{w}_t)$$
\end{frame}

\begin{frame}{Newton's Method}
    \small
    This result is a direct consequence of the underlying mathematical nature of \textbf{Ridge Regression}. The objective function is a quadratic and strictly convex function with respect to the weight vector $w$. 

    $$f(w) = \frac{1}{2n} \| Xw - y \|^2 + \frac{\lambda}{2} \| w \|^2$$

    \vspace{0.3cm}
    \textbf{The One-Step Convergence Lemma:}\\
    \textit{On nondegenerate quadratic functions, with any arbitrary starting point $w_0 \in \mathbb{R}^d$, Newton's method yields the global minimum $w^*$ in exactly one step ($w_1 = w^*$).}

    \vspace{0.3cm}
    Because the Ridge Regression objective function satisfies the condition of a nondegenerate quadratic function (a matrix with strictly positive eigenvalues has a non-zero determinant and is therefore invertible), this experimental behavior aligns exactly with optimization theory.
\end{frame}

\begin{frame}{Adagrad}
    Adagrad modifies standard Stochastic Gradient Descent by introducing a dynamic, per-coordinate learning rate. At each iteration $t$, we first pick a stochastic gradient $\mathbf{g}_t$.

    \vspace{0.3cm}
    \textbf{1. Gradient Accumulation}\\
    We accumulate the history of squared gradients for each individual coordinate $i$:
    $$[G_t]_i := \sum_{s=0}^{t} ([\mathbf{g}_s]_i)^2 \quad \forall i$$
    \textit{(This step tracks how strong the gradients have been in the past for the $i$-th coordinate).}

    \vspace{0.3cm}
    \textbf{2. Parameter Update}\\
    We then update each coordinate $i$ of our parameter vector $\mathbf{w}$:
    $$[\mathbf{w}_{t+1}]_i := [\mathbf{w}_t]_i - \frac{\gamma}{\sqrt{[G_t]_i}} [\mathbf{g}_t]_i \quad \forall i$$
\end{frame}

\begin{frame}{Adagrad}
    \textbf{The Adaptive Learning Rate:}\\
    The crucial part of this formula is the term $\frac{\gamma}{\sqrt{[G_t]_i}}$, which acts as our new coordinate-specific learning rate. 
    
    \vspace{0.3cm}
    \begin{itemize}
        \item By dividing the base learning rate $\gamma$ by the square root of the accumulated gradients, the algorithm automatically \textbf{reduces the step size} for coordinates that have historically had large gradients.
        
        \vspace{0.3cm}
        \item Instead, if a coordinate has had consistently small gradients, its learning rate remains relatively \textbf{higher}. 
    \end{itemize}

    \vspace{0.4cm}
    This mechanism speeds up convergence and reduces oscillations along directions where gradients are already large.
\end{frame}

\begin{frame}{Conclusions}
    \vspace{0.2cm}
    \begin{itemize}
        \item \textbf{Impact of $\lambda$ on Convergence:}\\
        Increasing the regularization hyperparameter $\lambda$ helps algorithms to converge, making the optimization's problem better conditioned. A higher $\lambda$ drastically reduces iterations and execution time.

        \vspace{0.4cm}
        \item \textbf{Algorithm Performance Comparison:}\\
        \vspace{0.1cm}
        \begin{itemize}
            \item \textbf{Newton's Method:} Converges in exactly 1 step across all $\lambda$ by leveraging second-order curvature.
            \item \textbf{Accelerated GD:} Best first-order method, can effortlessly navigates flat valleys.
            \item \textbf{Smooth GD ($1/L$):} Highly efficient for well-conditioned (high-$\lambda$) problems, but struggles heavily in flat scenarios.
            \item \textbf{Mini-batch SGD:} Safely converges, but stochastic noise makes strict high-precision possible only when learning rate becomes very small.
            \item \textbf{Adagrad:} Auto-tunes step sizes without theoretical parameters, but the monotonically shrinking learning rate causes slow convergence.
        \end{itemize}
    \end{itemize}
\end{frame}
